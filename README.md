# 整數加減過關－公開版

無個人姓名的國一正負整數加減練習 PWA，適合平板直式操作，也支援實體鍵盤。

## 功能

- 學生以姓名／暱稱及班級登入，裝置會記住登入資料
- 第 1～7 關為七種固定正負整數加減組合
- 第 8 關混合前七關
- 第 9 關依另外勾選的第 1～7 關自選混合
- 進入設定時不預選關卡，由學生自行選擇本次任務
- 第一、第二個數字範圍可分別調整
- 每關連續答對 30 題過關；答錯連擊歸零並立即訂正
- 累積五題錯題後進入逐題重練
- 練習滿 15 分鐘顯示休息提醒，可結束或繼續
- 中性 3D 小恐龍會依待機、答對、答錯與連擊切換表情
- PWA 可安裝、可離線，網路優先避免使用舊版快取
- 開始與結束採同一 Session 更新同一列試算表紀錄

## 連接全新的 Google 試算表

這個公開版應使用獨立 Apps Script 與獨立試算表，不要沿用綺妍版或幸平版。

1. 到 [Google Apps Script](https://script.google.com/) 建立新專案。
2. 把 `gas/Code.gs` 全部貼到 Apps Script 的 `Code.gs`。
3. 從上方函式選單選擇 `setup` 並按「執行」，依畫面完成授權。
4. 在執行記錄中開啟新建立的「整數加減過關－公開版學習紀錄」試算表。
5. 選擇「部署 → 新增部署作業 → 網頁應用程式」。
6. 執行身分選「我」，存取權選「任何人」，完成部署。
7. 複製結尾為 `/exec` 的網址，填入 `app.js` 最上方的 `RECORD_URL`（目前公開版已連接專用部署）。
8. 每次更新前端時，同步提高 `app.js` 的 `VERSION` 與 `sw.js` 的 `CACHE` 版本。

## GitHub Pages

建立新的公開 repository，把本資料夾內的檔案放在 repository 根目錄，推送後到
`Settings → Pages`，來源選擇 `Deploy from a branch`，分支選 `main / (root)`。
